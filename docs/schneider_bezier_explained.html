Turn a messy hand-drawn line into a few clean handles.

Plain goal: You sketch a stroke. Blender stores it as 50 little dots joined by straight lines. This algorithm — Schneider’s “Automatically Fitting Digitized Curves” — looks at those dots and says: “I can make the same shape with just 2–3 smooth Bezier curves.” That means fewer points, smoother in-betweens, and handles you can grab and tweak — huge for Grease Pencil.

What & Why

🎨 Your view in Blender

You draw a Grease Pencil stroke. Under the hood: drawing.strokes[0].points = an array of positions [x,y,z] in Blender Units (meters). A wiggly stroke can be 200 points.

digitized point straight segments

✨ What the algorithm does

It replaces that chain with 1–3 Bezier curves. Each curve is only 4 points: start, two handles, end. Same look, 10× fewer points, handles you can sculpt.

Bezier 101 — the 4 knobs

Think of a strip of rubber. You pin the ends ( p0 and p1 ). The two middle knobs (c1, c2) are magnets pulling the rubber. Move them, the curve bends — but never leaves the cage.

One cubic Bezier

Drag the orange handles in your head: closer to the ends = gentler bulge. Far = strong pull. This is how Grease Pencil stores handle_left / handle_right.

Why 4 knobs are enough

Splitting is a feature: If one Bezier can’t hug all dots within your allowed wobble (error), the algorithm cuts the line at the worst dot and tries again on each half. Recursion!

Inputs → Outputs

What you feed it

  • points — This means: an ordered list of your pen positions, each with x, y, z in meters. Example: [[0,0,0], [0.02,0.01,0], [0.05,0.03,0], …]
  • max_error — This means: how much slop you allow, as squared distance. Smaller = tighter hug, more Beziers. Example: 0.0004 (= 0.02 m = 2 cm max gap, squared). This code uses File: Executable/src/bezier_fit.cpp:250 fit_curve(points, max_error).

What you get back

  • BezierCurve — This means: a small bag with 4 points. In Python it comes as a flat 12-float array [p0x,p0y,p0z, c1x,…, p1z] per curve. See Executable/src/bezier_fit.h:10 struct BezierCurve { Vec3 p0,c1,c2,p1; }. This means: one Bezier is four 3-D positions.
  • The Grease Pencil glue: in Addon/core we’ll later turn these into a stroke where position = p0…p1 and handle_left = c1, handle_right = c2.
BU
Blender Units matter. This code uses meters (BU), never pixels. If you set max_error=0.01 you’re allowing ~10 cm of wiggle. For clean line art use ~0.0001–0.001 (1–3 cm squared = 1–3 mm actual gap).

Why this works for artists

You never see the math. You just set one knob: how much wiggle you tolerate. The code does the rest — it keeps adding Beziers until every dot is close enough. More wiggle allowed = fewer Beziers = chunkier shape. Tight tolerance = many small Beziers = hugs every nibble.

Step 1 — Tangents: which way is the pen going?

Tangent — This means: a unit arrow (length 1) that points along the stroke at a dot. We need one at the very start and one at the very end, because handles must leave the ends along the pen’s direction.

Vec3 ComputeLeftTangent(d, 0) { Vec3 t = d[1] - d[0]; // arrow from first to second dot V3Normalize(&t); // make it length 1 return t; // This means: unit direction at start }

Center tangent at a split — This means: average the two neighboring arrows and normalize. :79 ComputeCenterTangent(d, splitPoint) — (V1+V2)/2 then normalize. That’s how the two halves join smoothly.

Step 2 — Chord Length: “how far along am I?”

Parameter u — This means: a number between 0 and 1 saying “how far along the whole line this dot sits, measured along the real wiggly length”. 0=start, 1=end. We need it so each dot knows which t on the Bezier to compare against.

Visual check

If you spaced u uniformly (0, 0.2, 0.4…), a tight squiggle would be stretched and a long straight run squished. Chord length keeps the u spacing true to the pen’s travel.

u
Example: dots at distances 0, 2, 5, 9 meters along the line → cumulative 0,2,5,9 → divide by 9 → u = [0, 0.22, 0.55, 1.0]. The middle dot isn’t at 0.5, it’s at 0.55 because the polyline was longer on one side.

Step 3 — Least Squares: slide handles until “least wobble”

GenerateBezier — This means: given the dots and their us and two tangent arrows, find the two handle distances alpha_l and alpha_r along those arrows that make the Bezier sit closest (squared distance) to all dots at once. bezier_fit.cpp:98

What slides?

Least-squares — This means: add up the squared gap for every dot, move handles until the total is as small as possible. The little 2×2 math finds that sweet spot in one shot.

// bezier_fit.cpp:109 (verbatim) // Compute the A’s for (i=0;i<nPts;i++) { V3Scale(&v1, B1(u[i])); V3Scale(&v2, B2(uPrime[i])); A[i][0]=v1; A[i][1]=v2; } // C and X, then alpha via determinants det_C0_C1 = C[0][0]*C[1][1]-C[1][0]*C[0][1]; alpha_l = (det==0)?0 : det_X_C1/det_C0_C1; This means: build two equations that say “handle distances that best cancel the wobble”, solve them with high-school determinant arithmetic.

Step 4 — How bad? And where to cut?

ComputeMaxError — This means: walk every interior dot, evaluate the Bezier at its u with BezierII(3, curve, u) (De Casteljau’s triangle — repeatedly halve between control points), measure squared distance, keep the biggest. bezier_fit.cpp:181

biggest gap → cut here

The decision

If it’s good enough → DrawBezierCurve is called (in our C++ we push to out vector :224). If it’s close but not quite (maxError < error*4) → try re-aiming. If still bad → split at that worst dot and start over on each half.

Step 5 — Newton: “slide my u to the perpendicular spot”

NewtonRaphsonRootFind — This means: for one dot, look at where it sits relative to the curve and nudge its u a little closer to where a dropped perpendicular would hit the curve. Repeat for all dots → new uPrime. Then rebuild handles. bezier_fit.cpp:162 — Try up to 4 times.

Q_u = BezierII(3, Q, u); // point on curve Q1_u = BezierII(2, Q1, u); // first derivative (tangent) Q2_u = BezierII(1, Q2, u); // second derivative numerator = (Q_u-P)·Q1_u; // This means: how much Q−P sticks out along the tangent denominator = Q1_u·Q1_u + (Q_u-P)·Q2_u; uPrime = u - numerator/denominator; // nudge u toward perpendicular This means: Newton’s trick — one quick division to jump closer to “closest point on curve”.

In practice this shaves the error fast — the handles get a second, third, fourth chance before we give up and split.

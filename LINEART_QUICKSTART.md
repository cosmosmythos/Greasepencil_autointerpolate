# Quick Start - Lineart Import

## How to Use

1. **Open Blender 4.3+** with addon enabled
2. Go to **File > Import > Grease Pencil Line Art**
3. Select your image (PNG, JPG, BMP, TIFF)
4. Adjust settings:
   - **Auto Threshold**: ON (recommended)
   - **Despeckle**: 10+ (removes noise)
   - **Simplify**: 2.0 (reduces points)
   - **Scale**: 0.01 (adjust as needed)
5. Click **Import Line Art**

## What to Expect

✅ Strokes appear in a "LineArt" layer  
✅ No external dependencies required  
✅ Works on Windows, macOS, Linux

## Tips

- **Clean lineart** works best (black lines on white)
- For **sketchy art**, increase despeckle value
- Adjust **scale** to fit your scene
- Lines are placed at current frame
